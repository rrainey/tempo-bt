This snap-to-close enclosure was designed using Fusion 360 and optimized for printing using PLA filament on a Creality Ender V3 KE printer.

## Print Settings

I used the default settings in Creality Print for PLA-CR printing with a 0.4mm head and 0.2mm resolution. These settings were used for all three parts.

For other printers, here's what that amounts to:

| Parameter | Description |
|---|---|
| Filament Type    | Standard PLA |
| Print Resolution | 0.2 mm |
| Brim             | None |
| Supports         | None - enable if Pushbutton insert doesn't fit well |
| Infill           | Slicer Default (15%?) |

## Assembly

Two M2.5 brass inserts must be installed in the bottom half of the enclosure. M2.5 x 6 screws secure the PCB to the bottom enclosure.
